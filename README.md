# 批量文件去密码工具

一个 Windows 本地小工具，用于批量移除 **已知密码** 的 PDF / Word / PPT / Excel / WPS / ODF / ZIP / 7Z / RAR 文件的密码。

> 本工具不能破解密码，也不能绕过 DRM。密码忘了请找文件来源。

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `批量解密文件.bat` | 启动入口，双击运行或把文件拖到它上面 |
| `unlock_files.py` | 主程序（Python + tkinter 图形界面） |

## 使用方法

### 方法 A：拖拽文件（推荐）

1. 选中一个或多个要解密的文件（可混合 PDF、Word、PPT、Excel、WPS、ODF、ZIP、7Z、RAR）。
2. 一起拖到 `批量解密文件.bat` 上，松开鼠标。
3. 弹出窗口，每行显示：类型、文件名、密码框、所在文件夹。
4. 在每个密码框输入对应密码（**打开不需要密码的留空**）。
5. 点击右下角 **开始解密**。
6. 弹窗显示成功/失败数量，可点 **保存日志** 导出 txt。
7. 去原文件所在文件夹查看输出：
   - PDF / Office / WPS / ODF：生成 `原文件名_无密码.后缀`
   - ZIP / 7Z / RAR：生成 `原文件名\` 文件夹，里面是解压后的内容
   - 重名时自动加 `(1)`、`(2)`，不覆盖已有文件。

### 方法 B：双击打开后添加

1. 双击 `批量解密文件.bat`。
2. 点击 **添加文件...** 选择多个文件，或 **添加文件夹...** 递归扫描整个文件夹。
3. 填写密码，点击 **开始解密**。

### 常用按钮

- **全部显示密码 / 全部隐藏密码**：方便核对。
- **清空列表**：清空当前列表。
- **保存日志**：把成功/失败结果导出为 txt。

## 环境依赖

- Python 3（安装时勾选 `Add Python to PATH`）
- 依赖库：

```bash
pip install pymupdf msoffcrypto-tool pyzipper py7zr rarfile -i https://pypi.tuna.tsinghua.edu.cn/simple
```

RAR 解压还需要系统安装 WinRAR，或提供 `UnRAR.exe` 并加入 PATH。

## 常见问题

### 1. 双击 bat 闪一下就没了

- 原因：Python 未安装或未加入 PATH。
- 解决：重新安装 Python，勾选 `Add Python to PATH`。安装后重启 cmd。

### 2. 提示缺少模块，如 `No module named 'fitz'`

- 原因：依赖未安装成功。
- 解决：重新运行：

```bash
pip install pymupdf msoffcrypto-tool pyzipper py7zr rarfile -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 3. 提示“密码错误或为空”

- 确认密码大小写、空格是否正确。
- PDF 如果只是限制复制/打印、打开不要密码，密码留空即可。
- 如果密码确实忘了，本工具无法破解，请联系文件提供者。

### 4. WPS 文件失败

- `msoffcrypto` 对 WPS 旧版加密支持有限。
- 解决：用 WPS 打开后另存为 `.docx/.xlsx/.pptx`，再放入本工具。

### 5. OpenDocument（.odt/.ods/.odp）失败

- 支持有限。建议用 LibreOffice 打开后另存为 MS Office 格式，再处理。

### 6. 旧版 `.doc/.ppt/.xls` 失败

- 旧格式加密方式多样。建议用 Office 打开后另存为 `.docx/.pptx/.xlsx`，再处理。

### 7. RAR 解压失败

- `rarfile` 需要系统有 `unrar` 或 WinRAR。
- 解决：安装 WinRAR，或下载 `UnRAR.exe` 放到工具文件夹，并把该文件夹加入系统 PATH。

### 8. 提示“未加密，已复制”

- 说明该 Office 文件本来就没有密码，工具已复制一份 `_无密码` 版本，内容相同。

### 9. 压缩包解压后在哪里？

- 在同目录生成 `原压缩包名\` 文件夹，内容已解压。
- 压缩包本身无法“去掉密码后仍保持压缩”，所以是解压形式。

### 10. 提示“检测到不安全的路径”

- 压缩包内包含 `../` 等路径遍历条目，可能恶意。工具已阻止解压，请检查压缩包来源。

### 11. 处理很多文件时界面卡住

- 正常现象，主线程在逐个处理。等待完成即可。不要强制关闭。

### 12. 输出文件会覆盖原文件吗？

- 不会。输出为 `_无密码` 新文件或新文件夹，原文件保留。

### 13. 如何卸载/删除工具？

- 直接删除整个工具文件夹即可。依赖库可用 `pip uninstall` 卸载，但一般不需要。

## 限制与注意事项

1. **仅限已知密码**
   本工具不能破解密码，不能绕过 DRM。密码忘了请找文件来源。
2. **合法使用**
   只处理你本人创建、或已获得授权处理的文件。请勿用于侵权或非法用途。
3. **格式支持有限**
   - PDF：支持常见加密，DRM 保护的 PDF 不支持。
   - MS Office：`.docx/.pptx/.xlsx` 支持较好；旧版 `.doc/.ppt/.xls` 可能失败。
   - WPS / ODF：支持有限，建议另存为 MS Office 格式。
   - 压缩包：ZIP/7Z 支持较好；RAR 需要系统 `unrar`。
4. **压缩包是解压而非“去密码压缩”**
   输出为文件夹，不是无密码压缩包。
5. **安全性**
   已加入路径遍历检查，但仍建议只处理可信来源的文件。
6. **性能**
   大文件或大量文件处理较慢，界面可能短暂无响应。
7. **输出文件保密**
   去掉密码后文件更易被他人查看，请注意存放和传输安全。
8. **不提供密码恢复**
   如果密码丢失，本工具无法帮助恢复。
